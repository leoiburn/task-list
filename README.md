# task-list

My **first programming project ever**. 🐣

## What is it?
A simple to-do list that runs in the terminal. You can add tasks, see them, and remove them when they are done.

## Why I made it
I wanted to learn how Python works: how to write variables, loops, `if` statements, and functions. Building something small and real was the easiest way to practice.

## What I learned
- How Python code is written (the syntax)
- How to take input from the user and show output
- How to keep a list of things in memory and change it
